What is this

A working mini search engine over ten public-domain novels from Project Gutenberg. Built for CECS 429 as a way to turn the classroom IR concepts into something you can actually type into.

Plain words rank by tf-idf or BM25. Wrap a phrase in "quotes" for exact match. Use * for a wildcard. Use AND, OR, NOT for Boolean search. Misspell a term and the system suggests a correction.

The corpus

    Corpus from Project Gutenberg. Source on GitHub.
