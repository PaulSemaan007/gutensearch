02 GutenSearch

02. Problem Statement

Build a working search engine that uses everything.

  • Index a real natural-language corpus
  • Support Boolean, phrase, wildcard, and ranked queries
  • Offer two ranking algorithms for comparison, tf-idf cosine and BM25
  • Correct misspelled queries
  • Deploy as a static site with no backend
03 GutenSearch

03. Dataset

Ten public-domain novels from Project Gutenberg.

Around 778,000 tokens total across ten works spanning gothic horror, detective fiction, social satire, science fiction, and children's literature.

05 GutenSearch

05. Indexing

A positional inverted index plus a 3-gram index.

  • Lowercase, alphabetic tokens, no stemming
  • Stopwords stay in the index so phrase queries work
  • Positions stored as deltas from the previous one
  • Roughly 40 percent smaller than absolute positions
# a posting in index.json
"darcy": {
  "df": 1,
  "p": [["1342",
        [147, 312, 88, ...]]]
}

06. Query Evaluation

Four query modes, auto-detected from the input.

Input shapeModeImplementation
"two words"phrasepositional posting intersection
runn*wildcardk-gram intersection plus regex filter
a AND b NOT cbooleanshunting yard to RPN, set ops
vampire blood transylvaniarankedtf-idf cosine or BM25, top K

If a ranked query returns nothing, spelling correction kicks in. Damerau-Levenshtein edit distance over candidates that pass a 3-gram Jaccard threshold.

07 GutenSearch

07. Ranking

Two scoring schemes, one dropdown.

tf-idf cosine (lnc.ltc)
score(q, d) = Σt∈q   (1 + log tfq,t) · log(N / dft) · (1 + log tfd,t)  /  ‖q‖2 ‖d‖2
BM25 (k1 = 1.5, b = 0.75)
score(q, d) = Σt∈q   idf(t) · (k1 + 1) tfd,t  /  (tfd,t + k1 · (1 − b + b · |d| / avgdl))

Both rankers return the top K. K defaults to 10, configurable in the UI.
